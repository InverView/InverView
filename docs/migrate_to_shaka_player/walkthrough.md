# 修正内容の確認 - Shaka Player への移行

再生エンジンを `hls.js` から `shaka-player` に移行し、DASH 再生のサポートを追加しました。

## 修正内容の要約

- **`package.json`**:
    - `shaka-player` を追加。
    - `hls.js` を削除。
- **`src/components/VideoPlayer.tsx`**:
    - 再生ロジックを Shaka Player に完全に置き換えました。
    - `dashUrl` が利用可能な場合、優先的に DASH ストリームを再生します。
    - DASH がない場合は HLS、それ以外は直接ストリームというフォールバック構造を実装しました。
    - エラーハンドリングを追加し、再生失敗時の詳細をコンソールに出力するようにしました。
    - 自動再生、ループ再生、シーク位置の維持（`initialPositionSeconds`）の機能を維持しました。

## 修正後の動作

1. 動画ページを開くと、Shaka Player が初期化されます。
2. インスタンスの設定（URL、開始位置）が適用され、再生が開始されます。
3. `dashUrl` がある動画（多くの Invidious インスタンスで提供されています）では、より安定した適応型ビットレート再生が可能になります。
4. 下部のリンク集に「DASH 直リンク」が表示されるようになりました。

## 検証手順

- [ ] 動画再生ページを開き、動画が正常に再生されることを確認。
- [ ] 設定から「自動再生」や「ループ」を変更し、正しく動作することを確認。
- [ ] ブラウザのコンソールを開き、Shaka Player の初期化や読み込みに関するエラーが出ていないことを確認。
- [ ] DASH ストリームが提供されている場合、DASH で再生されていることを確認（ネットワークタブで `.mpd` またはセグメントファイルの読み込みを確認）。
