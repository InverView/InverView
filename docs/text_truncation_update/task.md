# タスク: 動画カード等のテキスト省略処理の実装

## 目的
ホーム画面、検索画面、動画再生ページ（関連動画）などで、タイトルやチャンネル名、説明文が長すぎる場合に適切に省略（...）を表示し、レイアウトが崩れるのを防ぐ。

## サブタスク
- [x] `VideoCard.tsx` のメタデータ（チャンネル名、視聴回数など）に省略処理を適用。
- [x] `ChannelCard.tsx` のチャンネル名に省略処理を適用。
- [x] `PlaylistCard.tsx` のメタデータに省略処理を適用。
- [x] `HashtagCard.tsx` のタイトルと説明に省略処理を適用。
- [x] 各カードのタイトル（2行まで表示）の動作確認。
