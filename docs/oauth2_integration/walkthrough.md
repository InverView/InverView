# 修正内容の確認 (Walkthrough): Invidious OAuth2.0 連携

## 実施した変更

### 1. アカウントセクションの追加 (`SettingsPage.tsx`)
- 設定画面に新しく「アカウント」セクションを新設しました。
- インスタンスへのログインをガイドするテキストと、ログインボタンを配置しています。

### 2. OAuth2.0 (authorize_token) フローの実装
- 「Invidious でログイン」ボタンをクリックすると、設定されているインスタンスの認証ページへリダイレクトされます。
- 必要なスコープ（登録チャンネル、プレイリスト、設定など）を自動的に要求します。

### 3. 自動トークン処理
- 認証成功後にアプリに戻った際、URL に含まれるトークンを自動的に検出し、アプリの設定に保存します。
- 保存後は URL をクリーンアップし、ログイン成功の通知を表示します。

### 4. ログイン状態の管理
- ログイン中は「ログイン済み」のステータスが表示され、ワンクリックでログアウト（トークンの削除）が可能です。

## 確認事項
- [ ] 「Invidious でログイン」をクリックして、インスタンスの認証画面に遷移するか。
- [ ] 認証後に設定画面に戻り、「Invidious ログインに成功しました」というアラートが出るか。
- [ ] アカウントセクションが「ログイン済み」表示に切り替わるか。
- [ ] 「ログアウト」をクリックして、トークンが削除されるか。

## 注意事項
- この機能は、設定されている「インスタンスURL」に対して動作します。ログイン前に正しいインスタンスURLが適用されていることを確認してください。
