# タスク: Invidious OAuth2.0 連携の導入

## 目的
ユーザーが Invidious アカウントに簡単かつ安全にログインできるように、OAuth2.0 形式の認証フローを導入する。これにより、登録チャンネルやプレイリストの同期が可能になる。

## サブタスク
- [x] `SettingsPage.tsx` に `useEffect` を追加し、URL パラメータからのトークン取得を実装。
- [x] `handleInvidiousLogin` 関数を実装し、`authorize_token` エンドポイントへのリダイレクトフローを構築。
- [x] 設定画面に「アカウント」セクションを追加し、ログイン/ログアウトボタンを配置。
- [x] トークン取得後の URL クリーンアップと通知の実装。
- [x] 手動トークン入力欄にヘルプテキストを追加。
