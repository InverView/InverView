# 実装計画: プロジェクト保護用ガイドラインの作成

## 1. 目的
AI (Antigravity等) がコードを編集する際に、プロジェクトの整合性を保ち、意図しない破壊を防ぐための明確なルールを定義する。

## 2. 実装内容
ルートディレクトリに `SAFETY.md` を作成し、以下の項目を記載する。

- **基本的な考え方**: 「動いているものを壊さない」「既存のパターンを優先する」
- **スタイリング**: Fluent UI v9 の使用、`useStyles` への準拠
- **コード品質**: コメントの維持、不要な削除の禁止
- **レスポンシブ**: モバイルファーストの維持
- **API/状態管理**: 既存の `SettingsProvider` や API 通信パターンの尊重

## 3. 手順
1. `SAFETY.md` をルートに作成。
2. 内容を日本語で詳細に記述。
3. 完了後に `walkthrough.md` を作成。
