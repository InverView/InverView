# 実装計画：下スワイプアニメーションの改善およびミニプレーヤー動画表示バグの修正

本ドキュメントでは、モバイル端末での動画再生ページにおける下スワイプジェスチャの動作（アニメーションの滑らかさ、中間点到達時のミニプレーヤーへの吸い込みアニメーション）の改善、およびミニプレーヤーで動画が表示されないバグの修正計画を定義します。

---

## 変更の概要と目的

1. **ミニプレーヤーでの動画表示バグ修正**
   * **問題:** ミニプレーヤー（`MiniPlayer`）のカードが `zIndex: 45` であるのに対し、動画の実体（`#inverview-global-video-host`）の `zIndex` が `44` となっているため、動画要素が不透明なカードの背後に隠れてしまっています。
   * **解決策:** `VideoPlayer.tsx` において、ミニプレーヤーモード（`miniMode === true`）の際の `zIndex` を `46` に引き上げます。タッチイベントは透過するため、操作性には影響しません。

2. **スワイプ追従時のカクつき改善 (遅いスワイプ時のガタつき解消)**
   * **問題:** スワイプドラッグ中に React のステートを頻繁に更新（リレンダリング）していたため、コンポーネントツリー全体の再描画コストが発生し、特にゆっくりスワイプしている際に画面がカクつく（ジッター）現象が発生していました。また、指を離した際にも transition が正しく効きませんでした。
   * **解決策:** スワイプ中のアニメーション表現を **「DOMの直接操作（ノン・ステート／ゼロ・リレンダリング方式）」** にアップグレードします。
     `pageContainerRef` および `progressBarRef` を介して、タッチムーブ時に直接 DOM の `style.transform` や `style.opacity` を書き換えます。これにより、スワイプ中の React 再描画コストを **完全にゼロ** にし、低スペック端末や遅いスワイプ時でも 60fps / 120fps 貼り付きの極限の滑らかさを実現します。

3. **中間点（140px）到達時のプレミアムな吸い込みアニメーション実装**
   * **問題:** 中間点（140px）に到達した瞬間に即座にページ遷移（`navigate`）が行われるため、画面が切り替わる前にアニメーションを表現する余地がありませんでした。
   * **解決策:** スワイプが中間点（140px）に達した（または下スワイプでのコミットが確定した）際、まずは DOM を直接操作してページ全体を滑らかに縮小（`scale(0.3)`）・フェードアウト（`opacity: 0`）・下スライドしながら消去するアニメーションを開始します。アニメーション完了（300ms後）に実際のミニプレーヤー化と画面遷移（`navigate`）を実行します。

4. **ミニプレーヤーからプレーヤー（最大化）へ移動する際の中間点アニメーション実装**
   * **問題:** ミニプレーヤーを上スワイプして拡大（最大化）する際、中間点に達した瞬間にアニメーション無しで即座にページ遷移が走り、視覚的な繋がりが遮断されていました。また、ミニプレーヤーのドラッグもステート管理のためカクついていました。
   * **解決策:** 
     * **送信側 (`MiniPlayer.tsx`):** スワイプをDOM直接操作に移行してカクつきを完全排除。上スワイプが閾値（-80px）の中間点に達した、あるいはタップ拡大が確定した際、ミニプレーヤーカード自体が `translateY(-120px) scale(1.15)` に向かって滑らかに拡大しながらフェードアウト（消失）するプレミアムコミットアニメーションを走らせてから、遷移を遅延実行します。
     * **受信側 (`WatchPage.tsx`):** マウントおよびロード完了時に、ページ全体を `translateY(100vh) scale(0.7)` から `translateY(0px) scale(1)` に向かって下からスッと吸い上がるように滑らかにフェードイン（拡大登場）させます。これにより、ミニプレーヤーが画面いっぱいに広がる超高品質なシームレス遷移を実現します。

## 検証計画

1. **ミニプレーヤーの表示確認**
   * 動画再生ページから戻る操作、または下スワイプを行い、ミニプレーヤーに動画が正しく表示されること（黒画面やサムネイルだけでなく、動画自体が動き続けること）を確認。
   * ミニプレーヤーのドラッグ移動、タップでの最大化、閉じるボタンが正常に動作することを確認。

2. **スワイプキャンセル時の確認**
   * モバイル表示において、動画ページおよびミニプレーヤーをスワイプして指を離した際、カクつくことなく元の位置へ吸い付くように滑らかにスプリングバックすることを確認。
   * 特に**非常にゆっくりスワイプ**している間も、一切のジッター（コマ落ち）なく指の動きに完全同期して吸い付くように動くことを確認。

3. **シームレスな相互遷移アニメーションの確認**
   * **最大化 → ミニプレーヤー:** 140px 以上下にスワイプした際、動画ページが滑らかに縮小・フェードアウトしながら下に消え去り、その直後にミニプレーヤーに自然に引き継がれることを確認。
   * **ミニプレーヤー → 最大化:** 上スワイプ（中間点 -80px）またはタップをした際、ミニプレーヤーカード自体が拡大・上昇しながらフェードアウトし、直後に再生ページ全体が画面下部から「ふわっ」と拡大上昇しながら登場し、一枚のカードが広がったかのようにシームレスに繋がって表示されることを確認。
