# 実装計画: UI コンポーネントのモダン化

## 概要
Fluent UI v9 の強力なコンポーネント群を活用し、WhoTube のコアな対話要素を刷新する。

## 実装詳細

### 1. ヘッダー設定メニュー (`Header.tsx`)
- `Menu` コンポーネントを使用して、テーマ、画質、地域設定を単一のドロップダウンに統合。
- `MenuItemRadio` を使用して、現在の設定状態を視覚的に表示し、直接変更可能にする。

### 2. 検索・チャンネルフィルター (`SearchPage.tsx`, `ChannelVideosPage.tsx`)
- `Select` 要素を `Combobox` に置き換え。
- `filterField` スタイルを作成し、ラベルと入力のバランスを最適化。
- 検索ページのデスクトップ表示用グリッドを 5 カラムに調整し、リセットボタンを含めて 1 行に収める。

### 3. 設定スライダー (`SettingsPage.tsx`)
- 6 箇所の `input type="range"` を `Slider` に移行。
- Fluent UI のテーマに沿った、一貫性のあるスライダーデザインを適用。

### 4. 動画カード (`VideoCard.tsx`)
- `Card` コンポーネントの `image` (Avatar) および `action` (Button) スロットを使用。
- チャンネルアイコンの表示と遷移機能の実装。
- ホバー時のエフェクト (`shadow`, `translateY`) の微調整。

## 期待される効果
- ユーザーインターフェースの質感が向上し、「WhoTube」としてのブランド体験が強化される。
- 各コンポーネントが標準的な Fluent UI パターンに従うことで、メンテナンス性が向上する。
