# 修正内容の確認 - DASH URL パラメータの維持とエラー表示の改善

Invidious Companion 経由での DASH 再生において、セキュリティトークンなどが含まれるクエリパラメータが欠落していた問題を修正し、エラー発生時の詳細表示を改善しました。

## 修正内容の要約

- **DASH URL の構築ロジックの改善**:
    - Invidious の元の `dashUrl` に含まれているクエリパラメータ（`check`, `unique_res` など）を、Companion 用の URL に引き継ぐようにしました。
    - これにより、一部のインスタンスや動画で必要となる認証・検証用のパラメータが正しく Companion サーバーに渡されるようになります。
- **エラーハンドリングの強化**:
    - `VideoPlayer.tsx` の `loadManifest` 内でエラーが発生した際、Shaka Player のエラーコード（例: `3016`, `4032` など）を画面に表示するようにしました。
    - コンソールに詳細なログ（マニフェスト URL、読み込み成功/失敗）を出力するようにし、デバッグを容易にしました。
    - `LOAD_INTERRUPTED` エラー（ページ遷移時などに発生する正常な中断）をより確実に無視するようにログ出力を調整しました。

## 修正後の動作

1. 動画再生時、Invidious が生成した複雑なパラメータを含む DASH URL が Companion サーバーに正しく転送されます。
2. 再生エラーが発生した場合、「ストリームの読み込みに失敗しました (Error Code: XXXX)」のように具体的なエラーコードが表示されます。
3. デベロッパーツールのコンソールで、どの URL を読み込もうとして失敗したかを確認できます。

## 検証手順

- [ ] 動画を再生し、URL に `check=...` などのパラメータが含まれている場合でも正常に再生されることを確認。
- [ ] 再生に失敗した場合、画面にエラーコードが表示されることを確認。
- [ ] コンソールを開き、`Loading manifest: ...` および `Manifest loaded successfully` のログを確認。
