# サイドバーのデザイン崩れと最小化状態のバグ修正

サイドバーの展開・最小化状態におけるデザインの不整合、アイコンのズレ、メインコンテンツとのレイアウト同期問題を解消し、YouTube風のモダンなUIを実現する。

## 完了条件
- [ ] サイドバーの幅が展開時(200px)と最小化時(64px)で明確に区別され、CSS変数で管理されていること
- [ ] 最小化時にアイコンが水平方向の中央に配置されていること
- [ ] アクティブ状態の青いインジケーターが正しく左端に表示され、ズレがないこと
- [ ] メインコンテンツの余白がサイドバーの幅と完全に同期し、アニメーションが一致していること
- [ ] 設定ボタンがサイドバーの下部に固定されていること
- [ ] モバイル表示時にデスクトップ用のサイドバーが干渉しないこと
- [ ] **追加要件**: 開閉ボタン（Hamburger）をヘッダーのロゴ左に移動し、`Header.tsx` で制御する
- [ ] **追加要件**: `NavItem` に `href` を付与し、アクセシビリティを向上させる
- [ ] **追加要件**: `AppItem` またはロゴをヘッダーに配置する
