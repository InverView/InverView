# タスク: サイドバー最小化機能の修正

## 概要
サイドバーの最小化ボタンを押してもサイドバーが縮小されない、または表示が正しく切り替わらない問題を修正します。

## 実施事項
- [x] `Sidebar.tsx` における `styles.navHeader` のタイポ修正（`styles.toggleButton` への変更）
- [x] `Sidebar.tsx` の `NavDrawer` コンポーネントに明示的な幅（220px / 72px）と transition を設定
- [x] `AppShell.tsx` のコンテナ側の transition を `Sidebar.tsx` と同期
- [x] サイドバー縮小時の NavItem のスタイル調整（アイコンのセンタリング、テキストの非表示化の確実な適用）
- [x] トグルボタンと「ホーム」項目の間の垂直方向の余白を調整（視認性の向上）
- [x] 最小化状態での選択インジケーター（青い線）を展開時と同じフルハイトのデザインに統一
- [x] tokens のインポート不足によるランタイムエラーの修正
- [x] 最小化時の横スクロールバーの解消（overflowX: hidden の追加）
- [x] 最小化時の各要素の幅を 72px に厳密に固定し、位置ずれを修正
