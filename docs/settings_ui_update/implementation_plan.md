# 設定画面の使いやすさ向上およびモバイル全画面表示の実装計画

設定画面を使いやすくアップデートし、モバイルでは全画面表示とし、Fluent 3のデフォルト仕様に準拠した形で実装します。

## ユーザーレビューが必要な事項
特にありません。Fluent UI v9の標準コンポーネント（TabList, Tab等）を用いて、Windows 11の設定画面に似た使いやすいレイアウトを実現します。

## 提案される変更内容

### 設定画面コンポーネント (`SettingsPage.tsx`)

#### [MODIFY] [SettingsPage.tsx](file:///c:/Users/oronami/Music/invidious_react_client/src/pages/SettingsPage.tsx)
- **インポート追加**: `@fluentui/react-components` から `TabList` と `Tab` をインポートします。
- **モバイル・レスポンシブ判定**: `window.innerWidth` を監視する `isMobile` ステートを追加し、幅が768px未満の場合にモバイル用レイアウトを適用します。
- **スタイル定義のアップデート (`useStyles`)**:
  - `overlaySurface`: 幅を `960px` に広げ、高さを `80vh` に設定（デスクトップ）。モバイル環境（`@media (max-width: 768px)`）では `100vw`/`100vh` とし、マージンや角丸をなくして全画面表示にします。
  - `overlayBody`: 高さを `100%` とし、スクロールを無効化（`overflow: hidden`）。代わりにコンテンツエリア側をスクロールさせます。
  - `settingsLayout`: デスクトップでは `row`（横並び）、モバイルでは `column`（縦並び）になるフレックスボックスレイアウトを追加します。
  - `sidebar`: デスクトップでは幅 `220px` の固定サイドバー（縦タブ）。モバイルでは横スクロール可能なタブリスト。
  - `contentArea`: 設定項目を表示するエリアで、縦スクロール（`overflow-y: auto`）をサポート。
- **UI構造の変更**:
  - 設定全体を9つのカテゴリ（一般、履歴と検索、再生、視聴画面、外観、アカウント、Companion、Last.fm、詳細）に分割し、`activeTab` に応じて該当する `SectionCard` のみを表示します。
  - これにより、1つの画面でスクロールが非常に長くなる問題を解決し、タブクリックで目的の設定へ瞬時にアクセス可能にします。

## 検証計画

### 自動テスト
- 既存のテストが正常にビルド・通過することを確認します。
  - `npm run lint`
  - `npm run test`

### 手動検証
- ブラウザの開発者ツールを用いて、デスクトップ表示（2ペイン）とモバイル表示（全画面表示・上部タブスクロール）が崩れずに動作することを確認します。
- 各タブを切り替えた際に、該当する設定項目が正しく表示されること、および切り替え時に設定変更のハンドラーが正しく機能することを確認します。
