# 修正内容の確認：チャンネル画像の表示不具合修正

動画再生ページおよびチャンネルページで、正しいチャンネル画像が表示されない問題を修正しました。

## 実施した変更

### 1. 型定義の更新 (`src/types/invidious.ts`)
- `VideoObject` インターフェースに `authorThumbnails?: ThumbnailObject[];` を追加しました。これにより、APIから返されるチャンネル画像を型安全に扱えるようになりました。

### 2. 動画再生ページの修正 (`src/pages/WatchPage.tsx`)
- チャンネルアイコンとして、誤って動画のサムネイルを使用していた箇所を修正しました。
- `video.authorThumbnails` を優先的に使用し、存在しない場合のみ `video.videoThumbnails` をフォールバックとして使用するように変更しました。

### 3. Avatar コンポーネントの修正
Fluent UI v9 の `Avatar` コンポーネントで画像が表示されない原因となっていた、プロパティ指定の誤り（`src` ではなく `image={{ src: ... }}` を使う必要がある）を修正しました。

対象ファイル：
- `src/pages/ChannelPage.tsx`
- `src/components/ChannelCard.tsx`
- `src/components/CommentCard.tsx`

## 動作確認のポイント
1. **動画再生ページ**:
   - 動画タイトル下のチャンネルアイコンが、正しくそのチャンネルのアイコンになっているか確認してください。
2. **チャンネルページ**:
   - チャンネル名左側の大きなアイコンが正しく表示されるか確認してください。
3. **チャンネルカード (関連チャンネルなど)**:
   - チャンネル一覧に表示される各チャンネルのアイコンが表示されるか確認してください。
4. **コメント欄**:
   - 各コメント投稿者のアイコンが表示されるか確認してください。
