# 修正内容の確認: Companion 設定の簡略化

## 実施した変更

### 1. 型定義の整理
- `src/settings/types.ts` から `operator` モードを削除しました。モードは `default` と `custom` の2種類になりました。

### 2. 設定画面 (SettingsPage) の更新
- 「Invidious 運営者用」の選択肢を削除しました。
- 「Default (インスタンス推奨)」モードの動作を更新し、URL を `/proxy/` に設定すると同時に、シークレットキーとして環境変数 `VITE_COMPANION_SECRET` の値を自動的に読み込むようにしました。

### 3. デフォルト値の確認
- `src/settings/defaults.ts` は既に環境変数を優先するようになっているため、新規ユーザーや設定初期化時にも適切にシークレットキーが適用されます。

## 動作確認のポイント
- 設定画面の Companion セクションで選択肢が「Default」と「カスタム」のみになっていることを確認してください。
- 「Default」選択時に、環境変数で設定したシークレットキーが内部的に適用されることを確認してください（表示上は無効化されたフィールドに値が入ります）。
