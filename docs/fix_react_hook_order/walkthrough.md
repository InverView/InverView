# 修正内容の確認 - React Hook順序の修正

`Comments.tsx` におけるフック順序の不備を修正しました。

## 修正内容の要約

- **`src/components/Comments.tsx`**: 
    - `useMemo` フックの呼び出しを、`isLoading` および `isError` による早期リターンの前に移動しました。
    - これにより、コンポーネントがどの状態（ロード中、エラー、データあり）であっても、同じ順序で同じ数のフックが呼び出されるようになり、Reactの「フックの規則」を遵守するようになりました。

## 修正後の動作

1. 動画ページを開いた際、コメントのロード中に `Rendered more hooks than during the previous render` エラーが発生しなくなります。
2. ロード完了後、正しくコメントが表示されます。
3. ソート順の変更や追加読み込みも、フックの順序が固定されたため安全に動作します。
