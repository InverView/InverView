# 実装計画: VideoPlayer.tsx のエラー修正

## 現状の分析
`VideoPlayer.tsx` は、コードのコピー＆ペーストミスや編集の不備により、構文が崩れています。
- `useEffect` 内で `initPlayer` や `loadManifest` が重複、または不完全に定義されている。
- 文字列リテラルが閉じられていない（例: `setPlaybackError("こ`）。
- 関数外に迷い込んだコード片（例: `.code === 3016 ...`）が存在する。
- 変数が定義されていない場所で使用されている。

## 修正手順

### 1. コードの再構築
`VideoPlayer.tsx` の主要なロジックを再構成します。
- `useEffect` フックを整理し、Shaka Player の初期化 (`initPlayer`) とマニフェスト読み込み (`loadManifest`) を適切にカプセル化します。
- 構文エラー（未終了の文字列、迷い込んだコード片）を除去します。
- 型安全性を確保するため、必要な型定義を確認または追加します。

### 2. 未使用変数のクリーンアップ
警告として報告されている未使用のインポートや変数を削除します。
- `Text`, `Link`, `Card` (一部は使用されているが、トップレベルのインポートが重複している可能性があるため確認)
- `VideoSurface` (未使用警告があるが、コンポーネントとして定義されている)
- `styles` などの定義済みだが使われていないプロパティ

### 3. エラーハンドリングの強化
Shaka Player のエラーイベントリスナーを正しく実装し、ユーザーに分かりやすい日本語メッセージを表示するように修正します。

## リスクと対策
- Shaka Player のバージョン依存性: 既存のコードで使用されている API が最新の Shaka Player と互換性があるか確認しながら修正します。
- 再生ロジックの変更: 修正によって既存の再生機能（音声のみモード、DASH/HLS 切り替え）が壊れないよう注意します。
